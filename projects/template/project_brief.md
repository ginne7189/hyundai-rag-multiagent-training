# 개인 프로젝트 정의

## 오늘 해결할 문제

프로젝트 A의 변경 요청을 검토할 때 필요한 절차와 품질 증적을 근거와 함께 찾는다.

## 사용자

- 변경 요청자
- 품질 검토자
- 최종 승인 책임자

## 입력

- 프로젝트·제품·기준 시점이 포함된 업무 질문
- 승인된 절차 문서와 증적 현황

## 출력

- 근거와 출처가 있는 답변
- 누락·충돌·정보 부족 판정
- 자동 처리·사람 검토·실행 금지 상태

## AI가 하지 않는 일

- 최종 변경 승인
- 위험 수용
- 외부 시스템 상태 변경
- 실제 담당자에게 발송

## 완료 기준

- [ ] 업무 문서가 2개 이상이다.
- [ ] 평가 Case가 5개 이상이다.
- [ ] 정상·정보 부족·거절·사람 검토·금지 Case가 있다.
- [ ] 두 전문 역할과 독립 검증 기준을 설명할 수 있다.
